あなたの Orca echo の配列で、次に押すキーとレイヤーを案内します。

Chrome / Edge で使えます。読むだけで、キーボードの設定は変えません。Keychron Launcher を開いている場合は閉じてから押してください。

    キーマップと設定

    キーマップ

    USB でつないだ Orca echo から、キーマップ・長押しキー・コンボ・マクロを読み込みます（Chrome / Edge）。

    PC側の入力配列

    同じキーコードでも、OSの配列設定で出る記号が変わります（例: LS(N2) は US で @、JIS で "）。

    ショートカットの修飾キー

    物理配置について

    Launcher の画面どおりの配置です（左右7列ずつ、内側に縦長の Mouse キー、左親指に Space とホイール、右にトラックボール）。ZMK の keymap を読んだときは、キー数から近い並びを組みます。

    キーマップ編集

    キーボードから読み込んで、キー・長押しキー・コンボを変更し、まとめて書き込みます。書き込む前に、いまの設定を自動で保存します。
